# cpp-practice-2026

Домашние задания по курсу "Практическое программирование"


Как сдавать задания:
- Клонируете себе репозиторий
- Создаете внутри склонированного репозитория директорию со своим именем (например, vakhromeeva_e_a)
- В этой директории создаете еще одну с номером домашнего задания (hw_1, hw_2 и т д)
- В директории с номером домашнего задания добавляете файлы с решенными заданиями (1.cpp, 2.cpp  и т д)

Выставляете pull-request в мой репозиторий.
Далее я проверяю ваше задание и апрувлю ПР, если все впорядке или пишу замечания, если они есть.
